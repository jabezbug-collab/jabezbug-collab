## 👨‍💻 About Me

I'm a curious builder who loves turning ideas into working software, from full-stack web apps to Android apps and DIY electronics. Whether I'm writing code, wiring up an Arduino, or tuning my own Linux server, I enjoy understanding how things work from the ground up. My long-term goal is to become a **cardiologist**, blending medicine, biology, and software engineering to build technology that can make a real difference in healthcare.

---

## 🔭 What I'm Up To

- 🌐 **Current Focus:** Exploring full-stack web development, mobile app creation, and DIY electronics/hardware projects
- 🚧 **Current Projects:** Building standalone web apps, creating Android WebView applications, and hosting personal sites on a custom Linux server setup
- 🫀 **Future Goals:** Pursuing cardiology while merging medicine, biology, and software engineering
