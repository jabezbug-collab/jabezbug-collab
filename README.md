## `> ABOUT`

I build fast, high-converting storefronts and web apps, and I like it best when the code, the hardware and the design all come together. I also tinker with Arduino and Raspberry Pi, and I host my own sites on a custom Linux server. My long-term goal is to become a **cardiologist** and combine medicine, biology and software to build tech that matters in healthcare.

> *"Conversion is the only metric that truly matters in design."*
